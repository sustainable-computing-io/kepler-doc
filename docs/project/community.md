# Community

Kepler is an open source [CNCF](https://www.cncf.io/) project. Everyone is welcome to use it, ask questions, and contribute.

## Channels

- [#kepler-project](https://cloud-native.slack.com/archives/C05QK3KN3HT) on CNCF Slack ([get an invite](https://slack.cncf.io/))
- [GitHub discussions](https://github.com/sustainable-computing-io/kepler/discussions)

## Get help

1. Search or open an [issue](https://github.com/sustainable-computing-io/kepler/issues) for bugs and feature requests.
2. Start a [discussion](https://github.com/sustainable-computing-io/kepler/discussions) for questions and ideas.
3. Ask in [#kepler-project](https://cloud-native.slack.com/archives/C05QK3KN3HT) on CNCF Slack.

To report a vulnerability, follow the [security policy](https://github.com/sustainable-computing-io/kepler/blob/main/SECURITY.md).
